Hi!

I'm a Master's student in Computational Science and Engineering at EPFL (École Polytechnique Fédérale de Lausanne) in Switzerland. I completed my Bachelor's in Engineering Physics at IIT Roorkee in 2025, graduating as the Department Gold Medalist.

I'm interested in the systems that make data and machine learning work at scale, particularly data systems, ML systems and optimization. I've pretrained autoregressive and diffusion language models, built large-scale data pipelines and optimized query engines. I've also written parallel code for GPUs and HPC clusters and worked on classical machine learning and deep learning problems.
